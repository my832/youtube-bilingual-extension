youtube双语插件 / 翻译服务与字幕设置

01 / 翻译服务

密钥按服务独立保存到本机，不使用浏览器云同步。AI 接口请包含 /chat/completions；更换域名后保存时会请求该域名的访问权限。
MiMo 和自定义 AI 请按控制台填写；模型可随时修改。

02 / 字幕显示

0% 完全透明 · 100% 完全不透明以上外观设置立即生效并自动保存。
The world is full of stories.
世界充满了故事。
拖动进度时取消旧位置的未完成请求，优先翻译新位置附近。原文单词支持点击查词；悬停不会查询。

03 / 保存与检查

测试会发送一句 “Hello, welcome to YouTube.” 到已保存的服务。启用后，视频字幕会发送给所选翻译服务，可能产生 API 费用。查词仅在点击原字幕单词后触发。使用微软/谷歌时会向 Free Dictionary API 查询所点击的英文单词；AI 服务会结合字幕原句解释。密钥以明文形式存放在浏览器扩展本地存储，请勿分享个人浏览器配置文件。

适用于桌面 Chrome / Edge。无字幕视频不支持语音识别；字幕会受服务响应速度影响。默认关闭，配置后再启用。
